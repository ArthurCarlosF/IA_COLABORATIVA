Testes exigem imagem Docker aprovada pelo operador. Container sem rede, projeto somente leitura e limites de recursos. Não é um terminal livre no computador do participante.

Participantes descobertos
Gossip com anúncios assinados e identidades autorizadas. Descoberta distribuída; créditos ainda são validados pelo coordenador local.
Uso e contribuição
A parte gratuita renova no fuso configurado. Créditos extras são ganhos executando tarefas de outras contas. Trabalho próprio não gera crédito. Cada token completo é dividido entre os workers; não há duplicação por camada. As reservas não utilizadas são devolvidas ao terminar.
Esta versão usa identidades autorizadas e um banco local auditável. Ainda não implementa consenso público, prova de disponibilidade nem recompensa por ociosidade.
